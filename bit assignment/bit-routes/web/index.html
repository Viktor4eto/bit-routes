How to use:
  • Left-click on the map to add waypoints in sequence
  • Right-click to remove the last waypoint
  • The route will automatically update as you add waypoints

ℹ
Noise Generation Methods
  • Auto – Uses the fastest available method
  • Fast – FastNoiseLite (3-5x faster, requires pyfastnoiselite)
  • OpenSimplex – Original method (slower but always available)
ℹ
Path Cost Parameters

These numbers (0–10) tweak how the pathfinder evaluates terrain cost:

  • Land – Normal terrain; low cost, easiest path.
  • Mountain – Rockier terrain; medium cost.
  • Snow – High peaks; high cost, avoided if possible.

Higher values make the algorithm prefer alternative, cheaper routes.

            Routing Algorithms
            
    
              
  • A* – Best overall: finds optimal path efficiently using heuristics
    • 
              
  • Dijkstra – Guaranteed optimal but explores more uniformly (slower)
    • 
              
  • Greedy Best-First – Fast but not optimal; rushes toward goal
    • 
              
  • BFS – Finds path with fewest steps (ignores terrain costs)
    • 
              
  • Bidirectional A* – Searches from both ends simultaneously (fastest for long paths)
